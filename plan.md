## Etapa 6
- Crie um novo projeto Java
- Aplique princípios de projeto SOLID, em especial o princípio da responsabilidade única.
- Crie um repositório com GitHub.
### Monte um relatório expondo:
- Os requisitos do sistema.
- Evidências do repositório GitHub.
- Procure implementar testes no método main() do projeto para certificar-se de que tudo está funcionando.

## Etapa 7
- Com base no projeto Java implementado na etapa anterior:
- Crie um projeto de testes JUnit e inclua ao menos um teste unitário para alguma das funcionalidades implementadas.
- Prefira funcionalidades de cálculos simples e, se necessário, faça essa separação de responsabilidade no código (separando um cálculo ou uma regra específica em um método próprio).
- Funcionalidades com acesso ao banco de dados podem ser dispensadas desse teste.
- Se necessário, crie nova funcionalidade ou regra de negócio para aplicação do teste.
- Versione o projeto de teste no repositório criado na etapa anterior.
- Monte um plano de teste básico, prevendo teste para os principais requisitos já implementados ou que você planeje implementar no sistema web.

## Etapa 8
### Realize os seguintes passos:
- Crie wireframes e protótipos para as páginas planejadas para o sistema web.
- Crie páginas HTML para os wireframes planejados.
- Aplique estilo com CSS para as páginas criadas. Para melhor organização, separe o código CSS em arquivos próprios (.CSS).
- Implemente validações e funcionalidades dinâmicas às páginas com JavaScript. Para melhor organização, separe esse código em arquivos .JS.
- Os arquivos podem ficar em uma pasta apropriada ou já em um projeto web NetBeans, caso já tenha conhecimento disso.
- Não é necessário, neste momento, desenvolver funcionalidades de back-end, como conexão com banco de dados.

## Etapa 9
- Crie um projeto Java Web Spring MVC ou Spring REST no NetBeans.
- Com base em seu projeto desktop ou projeto definido na etapa 6, implemente as funcionalidades de seu projeto web, aplicando banco de dados e integrando com o front-end desenvolvido. Realize todos os ajustes que verificar necessidade.
- Integre também as funcionalidades separadas na etapa 7 desta fase do projeto integrador (PI), implementando outras novas, caso necessário.
- Aplique versionamento ao projeto, criando novo repositório.
- Realize os testes previstos no plano de teste desenvolvido nas etapas anteriores e utilize ferramentas de bugtracking para registrar as falhas encontradas, corrigindo-as.
